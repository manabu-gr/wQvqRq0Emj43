# おはなしボタン（トーキングボード）

iPadでの利用を想定した、タップ（視線トラッキング／マウス／トラックボールなど）でひとことを読み上げるコミュニケーション支援Webアプリです。

## 概要

- ボタンを押すと、あらかじめ設定した言葉を音声で読み上げます
- トップページから「気持ちボタン」「あいうえお表」「ことばの組み立て」の各ページに移動する、アプリのような構成
- 「ことばの組み立て」は、左のカテゴリータブ（からだ・きもち／してほしいこと／もの／呼びかけ・人）を選ぶと右の単語ボタンが切り替わる方式。ページ遷移なしで瞬時に切り替わり、選んだ単語は繋げて「発声」ボタンでまとめて読み上げる
- ブラウザ内蔵の音声合成（Web Speech API）を使用し、日本語の自然な音声を自動選択します
- 「緊急」ボタンから、離れた場所にいる家族のスマホへプッシュ通知を送信できます（全ページに常設）

## ファイル構成

```
talk-buttons-app/
├── index.html      ← トップページ（各ページへのメニュー）
├── kimochi.html    ← 気持ちボタンページ（よく使う要望）
├── aiueo.html      ← あいうえお表ページ（50音から文章を組み立てて発声）
├── kumitate.html   ← ことばの組み立てページ（カテゴリータブ切り替え式）
└── README.md       ← この説明書
```

カテゴリー（からだ・きもち等）を増やすときは、`kumitate.html`内の`CATEGORIES`オブジェクトに1つ追加するだけで、タブと単語ボタンが自動的に生成されます。ページファイルを増やす必要はありません。

## 公開方法（重要）

**このアプリはローカルファイルとして直接開くと、「緊急」ボタンの通知送信が動作しません。**
ブラウザのセキュリティ制限により、`file://` で開いたページは外部サーバーへの通信（ntfy.shへの送信）がブロックされるためです。

そのため、**GitHub Pagesなどの実在するWebサーバーに公開してから使う**必要があります。

### GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成（Publicで可）
2. 「Add file」→「Upload files」で全HTMLファイルと`README.md`をアップロードし、Commit
3. リポジトリの Settings → Pages で、Source を「Deploy from a branch」、Branchを「main」/「/(root)」にしてSave
4. 1分ほど待つと `https://【ユーザー名】.github.io/【リポジトリ名】/` で公開される
5. iPadのSafariでこのURLを開き、共有ボタン→「ホーム画面に追加」

音声読み上げ機能（気持ちボタン・あいうえお表）だけであれば `file://` で直接開いても動作しますが、緊急ボタンも使う前提であれば最初からGitHub Pages経由での利用を強く推奨します。

## 使い方

トップページ（`index.html`）を開くと、「気持ちボタン」と「あいうえお表」を選ぶメニューが表示されます。今後ページが増えても、ここから選ぶ形になります。

### 気持ちボタン（kimochi.html）

画面に表示された6つのボタンをタップすると、対応する言葉が読み上げられます。画面右上には、どのページにも共通の丸い「緊急」ボタンが常設されています。

| ボタン | 読み上げ内容 |
|---|---|
| おとうさん | おとうさん |
| あつい | あつい |
| さむい | さむい |
| お茶のみたい | お茶のみたい |
| トイレに行きたい | トイレに行きたい |
| かゆい | かゆい |

「緊急」ボタン（右上・常設）を押すと、「緊急です　すぐにきて」を音声再生＋家族のスマホへプッシュ通知します。

### あいうえお表（aiueo.html）

50音表からひらがなをタップして文章を組み立て、「発声」ボタンでまとめて読み上げます。

- 同じ文字を**素早く2回**タップ → 濁音（か→が、つ→っ、や→ゃ 等）
- 同じ文字を**素早く3回**タップ → 半濁音（は行のみ、は→ぱ）
- 同じ文字を**少し間を置いてゆっくり2回**タップ → 文字を2つ並べる（は→は で「はは」）
- 「、」ボタンで読点（間を取る）、「？」ボタンで疑問形のイントネーション
- 「ー」（伸ばし棒）は「ん」の下・「を」の左に配置
- 「発声」ボタンで読み上げ、読み終わると自動でクリア。「クリア」でいつでも即クリア

両ページとも、右下に相互リンクがあります。

### ことばの組み立て（kumitate.html）

左側のカテゴリータブ（からだ・きもち／してほしいこと／もの／呼びかけ・人）を選ぶと、右側の単語ボタンが瞬時に切り替わります。単語をタップすると、あいうえお表と同じように画面上部の欄に言葉が積み上がり、「発声」ボタンでまとめて読み上げます。読み終わると自動でクリアされます。

- 単語と単語の間には自動で間（全角スペース）が入り、読み上げ時に不自然にならないようにしています
- **カテゴリーをまたいで単語を組み合わせられます**。たとえば「呼びかけ・人」タブで「マナブ」を選んだあと「からだ・きもち」タブに切り替えて「あつい」を追加すると、「マナブ　あつい」とまとめて発声できます
- 「1つ削除」ボタンで直前に追加した単語だけを取り消せます
- 画面右上に「緊急」ボタンが常設されており、どのページからでも緊急連絡ができます

| カテゴリー | 色 | 内容 |
|---|---|---|
| からだ・きもち | 青 | あつい・さむい・かゆい・いたい 等の状態 |
| してほしいこと | 緑 | たべたい・のみたい・ねたい 等の要望 |
| もの | オレンジ | お茶・お水・ひざかけ 等の単語 |
| 呼びかけ・人 | 黄 | 家族や先生など、呼びかけたい相手 |

## 緊急ボタンの仕組み

- [ntfy.sh](https://ntfy.sh/) という無料のプッシュ通知サービスを利用
- アカウント登録不要。「トピック名」という合言葉のようなものだけで通知の宛先を管理する仕組み
- 通知を受け取る家族側は、無料の「ntfy」アプリ（App Store）をインストールし、同じトピック名を登録（購読）するだけ

### 家族側（受信側）の初回セットアップ

1. App Storeで「ntfy」を検索し、無料アプリをインストール
2. アプリを開き「＋」→「Subscribe to topic」
3. トピック名を正確に入力：コード内の `NTFY_TOPIC` の値と同じもの
4. 通知許可のポップアップで「許可」を選択

### 注意点

- トピック名は公開の合言葉のようなものなので、第三者に知られないよう管理してください（コード内に記載）
- 通知にはWi-Fi／モバイル回線どちらもオンラインである必要があります
- 複数人に届けたい場合は、家族それぞれが同じトピック名で購読するだけで全員に届きます（コード変更不要）

## 機能（共通）

- **キュー再生**：再生中に別のボタンを押しても割り込まず、順番待ちしてから再生されます（同時押し対策）
- **視覚フィードバック**：通常時・マウスオン（視線オン）時・クリック（決定）時・再生待ち・再生中で見た目が変化
- **音声の自動選択**：起動時に日本語かつ自然な音声（オンライン/ニューラル音声を優先）を自動選択。画面下部のプルダウンから手動変更も可
- **読み上げ速度**：ゆっくりめ（0.82倍速）に固定

## カスタマイズ方法

各HTMLファイルをテキストエディタで開き、以下の該当箇所を編集してください。

### ボタンの言葉を変える・増やす（kimochi.html）

```html
<button class="word-btn" data-text="読み上げたい文章">表示テキスト</button>
```

- `data-text` … 実際に読み上げられる文章
- ボタン内のテキスト … 画面に表示される文字。`<br>` で改行可

ボタン数を変える場合は、CSSの `.grid` の `grid-template-columns` / `grid-template-rows` も合わせて調整してください。

### 「ことばの組み立て」の単語・カテゴリーを変える（kumitate.html）

`<script>` 内の `CATEGORIES` オブジェクトを編集します。

```js
const CATEGORIES = {
  karada: {
    label: 'からだ・きもち',
    color: '#6fb7ff', hover: '#4f9fe8', text: '#ffffff',
    words: ['あつい', 'さむい', 'かゆい', /* ここに単語を追加 */]
  },
  // ...
};
```

- 既存カテゴリーに単語を追加・削除する場合は、`words` の配列を編集するだけです
- 新しいカテゴリーを増やす場合は、`CATEGORIES` にオブジェクトを1つ追加します。`color`/`hover`はボタンの色、`text`はボタンの文字色です（黄色など明るい背景色の場合は `text` を濃い色にして読みやすくしてください）。タブと単語ボタンは自動的に生成されるので、HTMLやCSSを直接いじる必要はありません

### 緊急ボタンの文面・宛先を変える（kimochi.html）

```js
const NTFY_TOPIC = 'gaku-talkapp-9fn4uzva5w';   // 通知の宛先（トピック名）
const EMERGENCY_TEXT = '緊急です　すぐにきて';   // 読み上げ＆通知本文
```

**注意**：緊急ボタンの処理は全ページ（kimochi.html／aiueo.html／kumitate.html）にそれぞれ同じコードが入っています。トピック名や文面を変える場合は、全ファイルで同じ箇所を修正する必要があります。

タイトルの日本語部分（`titleParam`）はHTTPヘッダーではなくURLクエリパラメータとして渡す実装になっています。ヘッダーに直接日本語を入れると送信エラーや文字化けの原因になるため、変更する場合もこの方式を維持してください。

### 読み上げ速度・声の高さを変える

```js
utter.rate = 0.82;   // 1.0が標準速度。小さいほどゆっくり
utter.pitch = 1.05;  // 1.0が標準の高さ。大きいほど高い声
```

### 色を変える

`:root` の中のCSS変数を編集します（`--btn`、`--btn-hover` など）。

### ボタンの間隔を変える

`.grid` の `gap` の値（現在40px）を変更してください。視線トラッキングで誤操作が多い場合は数値を大きくしてください。

## 動作環境について

- 音声合成の質はブラウザ・OSに依存します。**Microsoft Edge** は日本語の自然な音声（Nanamiなど）を搭載していることが多く推奨です
- より人間の声に近い自然さが必要な場合は、ElevenLabsなどのAI音声サービスで作成した音声ファイル（mp3）に差し替える構成へ変更することも可能です

## トラブルシューティング

- **緊急ボタンを押しても通知が来ない** → まずローカルファイル（`file://`）で開いていないか確認。GitHub Pages等の`https://`URLで開く必要があります
- **コードを修正してアップロードし直したのに反映されない** → ブラウザキャッシュが原因のことが多いです。Cmd+Shift+Rの強制リロード、それでもダメならシークレットウィンドウ（Cmd+Shift+N）で開いて確認してください
- **HTTPヘッダーに日本語を直接入れるとfetchが失敗する／文字化けする** → ヘッダーではなくURLクエリパラメータとしてURLエンコードして渡す方式にすること
